# Tutigas

Site estático da Tutigas para publicação no GitHub Pages.

## Publicar no GitHub Pages

1. Cria um repositório público no GitHub.
2. Carrega estes ficheiros para a raiz do repositório:
   - index.html
   - styles.css
   - script.js
   - Group-114.png
   - 3kg.png
   - 18kg.png
   - Garrafa-11kg.jpg
   - Garrafa-13kg.jpg
   - Garrafa-45kg.jpg
3. Vai a Settings > Pages.
4. Em "Build and deployment", seleciona:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
5. Guarda.
6. O GitHub vai gerar uma URL do tipo:
   https://seu-utilizador.github.io/nome-do-repositorio/

## Observações

- Este site é estático e funciona bem no GitHub Pages.
- Não depende de servidor backend.
- Pode ficar online 24/7 mesmo quando o computador está desligado.
